# サイトコンテキストローカライズ設計

## 目的

**サイトを訪れた住民が、政治資金可視化サイトではなく自治体財政可視化サイトであると正しく認識できるようにするため。**

現在のサイトは fork 元の政治資金可視化プロジェクト（team-mirai/marumie）の文言がそのまま残っており、メタデータ・説明文・フッター・法的ページ等あらゆる箇所に「政治資金」「チームみらい」「政治団体」等の表記がある。これをすべて自治体財政・CivicTechEzo の文脈に書き換える。

本作業はロジック変更を伴わない静的な文言差し替えであり、他フェーズと独立して着手できる。

---

## スコープ

### 対象

- **webapp**: 住民向けフロントエンドの全文言・メタデータ
- **admin**: 管理画面のメタデータ・ナビゲーション文言（Phase 0 で対応する最小限）

### 対象外

- `shared/accounting/account-category.ts` の勘定科目体系 → Phase 1-3 で自治体財政用に全面再設計するため、ここでは触れない
- admin の report コンテキスト（政治資金収支報告書関連）のドメインモデル・ビジネスロジック → Phase 1 以降で再設計
- admin の donor（寄付者）関連機能 → 自治体財政では不要な機能。Phase 1 以降で整理
- URL パス構造の変更（`/o/[slug]` 等） → 既存リンクの互換性を考慮し、本フェーズでは変更しない
- OGP 画像の差し替え → デザインアセットが別途必要なため、本フェーズのスコープ外

## 変更方針

### 用語マッピング

本フェーズで適用する基本的な用語対応表:

| 旧（政治資金） | 新（自治体財政） |
|---------------|----------------|
| 政治資金 | 自治体財政 / 財政データ |
| 政治団体 | 自治体 |
| まる見え政治資金 | 自治体財政まる見え |
| チームみらい | CivicTechEzo |
| 寄附で応援する | （削除） |
| 政治資金収支報告書 | 決算書 / 決算統計 |
| 収支の流れ | 歳入・歳出の流れ（Phase 2 で Sankey 再設計時に確定） |
| 未登録の政治団体 | 未登録の自治体 |

### 作業の進め方

1. **webapp のメタデータ・セクション文言** を先行して変更（影響範囲が明確で、住民がまず目にする箇所）
2. **webapp のフッター・ヘッダー・法的ページ** を変更
3. **webapp のフォールバックテキスト・アクセシビリティラベル・コメント** を変更
4. **admin の最小限の文言** を変更
5. 各ステップ完了後にビルドが通ることを確認
