# フェーズ3-2: 住民1人あたり換算表示 設計

## 目的

**住民が**、「数百億円」という実感の湧かない自治体の財政データを、「自分ごと」として捉えられるようにするため。

歳入100億円・歳出98億円と言われても規模感がわからない。「あなた1人あたりの支出は約49万円です」と表示すれば、自分の家計と比較でき、「高い」「安い」の判断がつく。

---

## スコープ

ダッシュボード上の金額表示を「全体の金額」と「1人あたりの金額」で切り替えるトグルを追加する。

### 切り替え対象

| セクション | 現状の表示 | 1人あたりモード |
|-----------|-----------|----------------|
| FinancialSummarySection | 歳入総額・歳出総額・実質収支 | 1人あたり歳入・歳出・収支 |
| SankeyChart | 各カテゴリの絶対額 | 各カテゴリの1人あたり額 |
| SummaryCard | 「支出は約X億円」 | 「住民1人あたりの支出は約X万円」 |
| ScissorsGraphSection（3-1） | 積立金・地方債の絶対額 | 1人あたり積立金・地方債 |

### 切り替え対象外

| セクション | 理由 |
|-----------|------|
| PerCapitaBalanceSection（3-1 C4） | 元から1人あたり表示のため不要 |
| MandatoryExpenseSection（3-1 B2） | 比率表示のため換算不要 |

## トグルUI

### 配置

ダッシュボードの財務セクション群の先頭、CashFlowSection の直前に配置する。

```
┌──────────────────────────────────────┐
│  ★ [ 全体の金額 | 1人あたり ] ← NEW │
├──────────────────────────────────────┤
│  CashFlowSection                     │
│  ...                                 │
```

### デザイン

セグメンテッドコントロール（ピル型の2択ボタン）。

```
┌──────────────────────────────────┐
│  ● 全体の金額  ○ 1人あたり     │
└──────────────────────────────────┘
```

- 選択中の側: 背景色 `#238778`、テキスト白
- 非選択の側: 背景色 `#F3F4F6`、テキスト `#6B7280`
- 人口の注釈を下部に小さく表示: 「※ 人口 ○○,○○○人（令和○年度）で換算」

---

## 状態管理

### 方針

トグル状態はクライアントサイドの React state で管理する。URL パラメータにはしない（ページ遷移を伴わず即座に切り替わる体験を優先）。

### 実現方法

現在の page.tsx はサーバーコンポーネントで、各セクションを直接配置している。トグル状態を複数のセクションで共有するため、**React Context** を使う。

**PerCapitaContext:**

- `isPerCapita: boolean` — 現在のモード
- `population: number` — 人口（換算に使用）
- `togglePerCapita: () => void` — モード切り替え

**PerCapitaProvider:**

- page.tsx 内で、トグル対象のセクション群をラップするクライアントコンポーネント
- `population` をサーバーから props で受け取り、Context に提供する
- children パターンで内側のサーバーコンポーネントは維持できるが、対象セクションはすべて既にクライアントコンポーネントのため問題なし

### ページ構造の変更

```
// page.tsx（サーバーコンポーネント）
<MainColumn>
  <PerCapitaProvider population={population} fiscalYear={fiscalYear}>
    <PerCapitaToggle />
    <CashFlowSection ... />
    <PerCapitaBalanceSection ... />   ← 3-1（トグル対象外だが配置上Provider内）
    <MandatoryExpenseSection ... />   ← 3-1（同上）
    <ScissorsGraphSection ... />      ← 3-1（トグル対象）
  </PerCapitaProvider>
  <TransparencySection ... />
  <ProgressSection ... />
  ...
</MainColumn>
```

## データフロー

### population の取得

現在の `loadTopPageData` は SankeyData のみを返している。population を追加で返す。

**変更:** `loadTopPageData` の返り値に `population: number` を追加する。

population の取得元は `FiscalYearSettlement.population`。`GetSankeyAggregationUsecase` の返り値に population を含めるか、loader 内で別途 `FiscalYearSettlement` から取得する。

後者が usecase の責務を変えずに済むため、loader 内で `fiscalSettlementRepository.findByMunicipalityAndYear` を直接呼び出して population を取得する。

### 1人あたり換算

換算はクライアントサイドで行う。サーバーで2種類のデータを生成するのではなく、元データ（全体の金額）と population を渡し、表示時に割り算する。

**換算ユーティリティ関数:**

`toPerCapitaSankeyData(data: SankeyData, population: number): SankeyData`

- 全リンクの `value` を `value / population` に変換
- `totalLatestBalance` も同様に変換
- ノード構造はそのまま維持
- population が 0 の場合は元データをそのまま返す

配置: `webapp/src/client/lib/per-capita.ts`

## 各コンポーネントの変更

### CashFlowSection

- Context から `isPerCapita` と `population` を取得
- `isPerCapita` が true の場合、SankeyData を `toPerCapitaSankeyData` で変換してから子コンポーネントに渡す
- SummaryCard と FinancialSummarySection と SankeyChart に渡す SankeyData が変換後のものになる

### FinancialSummarySection

- ラベルの変更が必要
- `isPerCapita` が true のとき:
  - 「歳入総額」→「1人あたり歳入」
  - 「歳出総額」→「1人あたり歳出」
  - 「実質収支」→「1人あたり収支」
- props に `isPerCapita: boolean` を追加

### SummaryCard

- `generateSummary` に `isPerCapita` パラメータを追加
- 1人あたりモード時のテンプレート例:
  - 基本: 「住民1人あたりの支出は約○万円。最も多いのは「○○」（○%）です。」
  - 赤字: 「住民1人あたりで見ると、収入約○万円に対し支出約○万円で、約○万円の赤字です。」
- 比率（%）は変わらないため、偏り強調・依存財源強調パターンはテキスト冒頭のみ変更

### SankeyChart

- SankeyData の link value が変わるだけで、チャート自体の描画ロジックは変更不要
- ツールチップの金額表示が自動的に1人あたりの値になる
- ノードラベル横に表示される金額も同様

### ScissorsGraphSection（3-1）

- Context から `isPerCapita` と `population` を取得
- 1人あたりモード時、各年度の `savingsBalance` と `debtBalance` を population で割る
- Y軸のスケールと単位表示が変わる
- 注意: 人口は年度によって異なるため、各年度のデータに population を含める必要がある
  - 3-1 設計の `ScissorsGraphPoint` に `population` フィールドを追加する

---

## formatAmount の挙動

既存の `formatAmount` は円単位の金額を万円/億円にフォーマットする。1人あたりモードでも同じ関数をそのまま使える。

例:
- 全体: 歳出 100億円 → `formatAmount(10000000000)` → 「100 億 円」
- 1人あたり（人口2万人）: → `formatAmount(500000)` → 「50 万円」

金額レンジが変わるだけで、フォーマットロジックの変更は不要。

## エッジケース

| ケース | 対応 |
|--------|------|
| 人口が 0 または未登録 | トグル自体を非表示にする。全体の金額モードのみ |
| 1人あたりで端数が出る | 円未満は四捨五入 |
| 3-1未実装の段階で先に3-2を実装 | ScissorsGraphSection 関連の変更はスキップ。CashFlowSection 内のみ対応 |
