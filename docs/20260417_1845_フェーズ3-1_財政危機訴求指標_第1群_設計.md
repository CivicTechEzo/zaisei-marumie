# フェーズ3-1: 財政危機訴求指標（第1群）設計

## 目的

**住民が**、自分のまちの財政状況の厳しさを「パッと見て直感的に理解できる」状態を作るため。

現在のダッシュボードはサンキー図と歳入歳出総額を表示しているが、「このまちの財政はヤバいのか？大丈夫なのか？」は伝わらない。第1群として、最もインパクトが大きく実装もシンプルな3つの指標を追加し、住民の「うちのまちマズいな」という直感的な気づきを引き出す。

---

## スコープ

[財政危機訴求指標と可視化設計](20260329_1603_財政危機訴求指標と可視化設計.md) で定義された第1群の3指標を実装する。

| ID | 指標名 | 可視化 | タイプ |
|----|--------|--------|--------|
| C4 | 1人あたり借金 vs 貯金 | バランスバー | スナップショット（単年） |
| B2 | 義務的経費比率 | 横棒バー | スナップショット（単年） |
| C1 | 貯金×借金ハサミグラフ | 折れ線2本 | 経年変化（複数年） |

## 利用するデータ

すべて `FiscalYearSettlement` モデルの既存フィールドから取得可能。新規フィールド追加は不要。

### C4: 1人あたり借金 vs 貯金

| 項目 | フィールド | 単位 |
|------|-----------|------|
| 地方債現在高（借金） | `localBondBalance` | 千円 |
| 積立金現在高（貯金） | `reserveFundTotal` | 千円 |
| 人口 | `population` | 人 |

- 1人あたり借金 = `localBondBalance × 1000 ÷ population`（円）
- 1人あたり貯金 = `reserveFundTotal × 1000 ÷ population`（円）

### B2: 義務的経費比率

| 項目 | フィールド | 単位 |
|------|-----------|------|
| 義務的経費計 | `expMandatoryTotal` | 千円 |
| 人件費 | `expPersonnel` | 千円 |
| 扶助費 | `expAssistance` | 千円 |
| 公債費 | `expDebtServiceNature` | 千円 |
| 歳出総額（性質別） | `expNatureTotal` | 千円 |

- 義務的経費比率 = `expMandatoryTotal ÷ expNatureTotal`
- 内訳比率: 各項目 ÷ `expNatureTotal`

### C1: 貯金×借金ハサミグラフ

| 項目 | フィールド | 単位 |
|------|-----------|------|
| 積立金現在高 | `reserveFundTotal` | 千円 |
| 地方債現在高 | `localBondBalance` | 千円 |
| 会計年度 | `fiscalYear` | 年 |

複数年度分のデータが必要。利用可能な全年度を対象とする。

## バックエンド設計

### リポジトリ変更

`IFiscalSettlementRepository` に複数年度データ取得メソッドを追加する。

**追加メソッド:**

```
findAllByMunicipality(municipalityId: bigint): Promise<FiscalYearSettlement[]>
```

- 指定自治体の全年度データを `fiscalYear` 昇順で返す
- C1（ハサミグラフ）で複数年度のデータが必要なため
- C4・B2は単年度データで足りるが、同じloader内で取得するため一括で取得する

### ドメインモデル

`domain/models/` に財政指標の型を定義する。

**FiscalIndicators（単年度の指標セット）:**

```
interface FiscalIndicators {
  // C4: 1人あたり借金 vs 貯金
  perCapitaDebt: number;       // 円
  perCapitaSavings: number;    // 円

  // B2: 義務的経費
  mandatoryExpenseRatio: number;  // 0〜1
  personnelRatio: number;         // 0〜1（内訳）
  assistanceRatio: number;        // 0〜1（内訳）
  debtServiceRatio: number;       // 0〜1（内訳）
  discretionaryRatio: number;     // 0〜1（自由に使える割合）

  // メタデータ
  fiscalYear: number;
  population: number;
}
```

**ScissorsGraphPoint（ハサミグラフの1年度分）:**

```
interface ScissorsGraphPoint {
  fiscalYear: number;
  savingsBalance: number;  // 千円
  debtBalance: number;     // 千円
}
```

**FiscalIndicatorsData（ページに渡す全データ）:**

```
interface FiscalIndicatorsData {
  current: FiscalIndicators;               // 表示中年度の指標
  scissorsGraph: ScissorsGraphPoint[];     // 全年度の貯金・借金推移
}
```

### ドメインサービス

`domain/services/fiscal-indicator-calculator.ts` に指標計算ロジックを配置する。

**責務:**

- `FiscalYearSettlement` から `FiscalIndicators` を算出する
- 複数年度の `FiscalYearSettlement[]` から `ScissorsGraphPoint[]` を算出する
- 人口が0の場合のガード（1人あたり計算で除算エラーを防ぐ）
- 歳出総額が0の場合のガード（比率計算で除算エラーを防ぐ）

**配置理由:**

- 複数フィールドにまたがる計算 → Domain Model ではなく Domain Service
- ビジネスルール（財政指標の定義）に基づくロジック → Application Service ではなく Domain Service

### ユースケース

`application/usecases/get-fiscal-indicators-usecase.ts`

**処理フロー:**

1. `municipalityRepository.findBySlug(slug)` で自治体を取得
2. `fiscalSettlementRepository.findAllByMunicipality(municipalityId)` で全年度データを取得
3. 表示対象年度のデータから `FiscalIndicators` を算出（ドメインサービス）
4. 全年度データから `ScissorsGraphPoint[]` を算出（ドメインサービス）
5. `FiscalIndicatorsData` を返す

### ローダー

`presentation/loaders/load-fiscal-indicators.ts`

- `unstable_cache` でラップ
- キャッシュキー: `["fiscal-indicators", slug, fiscalYear]`
- tags: `["fiscal-indicators"]`
- revalidate: `CACHE_REVALIDATE_SECONDS`（既存定数を共用）

### コンポーネント設計

#### C4: PerCapitaBalanceSection

**表示イメージ:**

```
┌──────────────────────────────────────┐
│ あなたの分の借金と貯金                │
│                                      │
│  貯金  5万円 ██░░░░░░░░░░░░░░░░░░░░  │
│  借金 50万円 ██████████████████████░  │
│                                      │
│  差額: 45万円（借金が貯金を上回る）    │
└──────────────────────────────────────┘
```

- 左右対比のバランスバーではなく、上下2本のバーで比較する形式を採用
- 貯金バー（緑系）と借金バー（赤系）を同じスケールで並べ、長さの差で直感的に伝える
- 金額は万円単位で表示
- 差額を文言で補足

**Props:**

```
interface PerCapitaBalanceSectionProps {
  perCapitaDebt: number;     // 円
  perCapitaSavings: number;  // 円
}
```

**実装方針:**

- CSS（Tailwind）のみで描画。チャートライブラリ不要
- サーバーコンポーネントとして実装可能（状態管理不要）

#### B2: MandatoryExpenseSection

**表示イメージ:**

```
┌────────────────────────────────────────┐
│ 削れない支出の割合                      │
│                                        │
│ ████████████████████████████░░░░░░░░░░ │
│ ├── 職員の給料 ──┤├ 福祉 ┤├ 返済 ┤     │
│       32%          18%     12%   残り38%│
│                                        │
│ 収入のうち62%は毎年決まった支出に       │
│ 消えます。自由に使えるのは38%だけです。  │
└────────────────────────────────────────┘
```

- 横棒バー1本に義務的経費の内訳を積み上げ表示
- 義務的経費部分（人件費・扶助費・公債費）を異なる暖色系で色分け
- 残りの部分（裁量的経費）を緑系で表示
- パーセンテージを各セグメントに表示
- 下部に平易な文言で要約

**Props:**

```
interface MandatoryExpenseSectionProps {
  mandatoryExpenseRatio: number;
  personnelRatio: number;
  assistanceRatio: number;
  debtServiceRatio: number;
  discretionaryRatio: number;
}
```

**実装方針:**

- CSS（Tailwind）のみで描画。チャートライブラリ不要
- 各セグメントの幅は `style={{ width: \`${ratio * 100}%\` }}` で動的に設定
- サーバーコンポーネントとして実装可能

#### C1: ScissorsGraphSection

**表示イメージ:**

```
┌────────────────────────────────────────┐
│ まちの貯金と借金の推移                  │
│                                        │
│  金額                                  │
│   │ ＼ 借金（地方債残高）              │
│   │   ＼          ／                   │
│   │     ＼      ／                     │
│   │       × ← 転換点                  │
│   │     ／  ＼                         │
│   │   ／     ＼ 貯金（積立金残高）      │
│   └──────────────────→ 年度            │
│     R1   R2   R3   R4   R5             │
│                                        │
│ 令和○年度に借金が貯金を上回りました。   │
└────────────────────────────────────────┘
```

- 2本の折れ線（貯金=緑系、借金=赤系）を同一グラフに重ねる
- 借金が貯金を上回っている領域を薄い赤で塗りつぶし
- 交差ポイント（転換点）がある場合はマーカーで強調
- 年度ラベルは「令和○年」表記
- 下部に交差の有無に応じた文言を表示

**Props:**

```
interface ScissorsGraphSectionProps {
  data: Array<{
    fiscalYear: number;
    savingsBalance: number;   // 千円
    debtBalance: number;      // 千円
  }>;
}
```

**実装方針:**

- チャートライブラリとして **ApexCharts**（`react-apexcharts`）を使用。既に `package.json` に含まれている
- area chart タイプで2系列を描画し、交差領域の塗りつぶしを表現
- レスポンシブ対応（ApexCharts の responsive オプション）

## 表示テキスト

各セクションの見出しと補足テキストは平易な表現を使う。

### C4: PerCapitaBalanceSection

- 見出し: 「あなたの分の借金と貯金」
- 補足テキスト（テンプレート）:
  - 借金 > 貯金の場合: 「住民1人あたり○万円の借金に対し、貯金は○万円です。」
  - 貯金 >= 借金の場合: 「住民1人あたり○万円の貯金があり、借金○万円を上回っています。」

### B2: MandatoryExpenseSection

- 見出し: 「削れない支出の割合」
- 補足テキスト（テンプレート）: 「収入のうち○%は毎年決まった支出（職員の給料○%、福祉・生活の支援○%、借金の返済○%）に消えます。自由に使えるのは○%だけです。」

### C1: ScissorsGraphSection

- 見出し: 「まちの貯金と借金の推移」
- 補足テキスト（テンプレート）:
  - 交差ありの場合: 「令和○年度に借金が貯金を上回りました。」
  - 交差なし（常に借金>貯金）の場合: 「借金は貯金を一貫して上回っています。」
  - 交差なし（常に貯金>=借金）の場合: 「貯金は借金を上回る水準を維持しています。」

## 年度表記

- グラフのX軸ラベル: 和暦の短縮表記（`R1`, `R2`, ... `R6`）
- テキスト中の年度: 「令和○年度」

変換ロジック: `fiscalYear - 2018` で令和年を算出（2019年=令和1年）。

## エッジケース

| ケース | 対応 |
|--------|------|
| 人口が0 | C4セクションを非表示 |
| 歳出総額が0 | B2セクションを非表示 |
| 年度データが1年度分のみ | C1セクションを非表示（折れ線が成立しない） |
| 該当年度のデータなし | 全セクションを非表示 |
| 積立金・地方債がともに0 | 各セクションはデータ通り0で表示（非表示にはしない） |
