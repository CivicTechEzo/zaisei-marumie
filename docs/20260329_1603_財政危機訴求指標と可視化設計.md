# 財政危機訴求指標と可視化設計

## 目的

**住民が**、自分のまちの財政状況の厳しさを「パッと見て直感的に理解できる」状態を作るため。

CivicTechEzoの価値観（気軽に見る→理解→気づき→共有→当事者意識）に基づき、決算カードから取得可能なデータの中から「うちのまちマズいな」と直感的に訴求できる指標を選定し、その可視化方法を定義する。

---

## 前提

- データソースは**決算カード（総務省統一様式Excel）**を前提とする
- 決算カードに含まれる全項目の中から、住民の直感に訴える指標を選定する
- 対象は北海道内179市町村＋道
- 決算カードには「類似団体平均値」が併記されており、比較表示に活用できる

---

## 指標分類

指標を以下の3カテゴリに分類する。

- **A. 経年変化型**: 複数年の推移を見せることで「じわじわ悪化している」を伝える
- **B. スナップショット型**: 単年の値だけで「今こうなっている」を伝える
- **C. 組み合わせ型**: 複数指標を同時に表示し、構造的な厳しさを伝える

---

## A. 経年変化型指標

### A1. 財政力指数（まちの稼ぐ力）

| 項目 | 内容 |
|------|------|
| 決算カード取得元 | 財政指標 |
| 値の意味 | 基準財政収入額 ÷ 基準財政需要額（3年平均） |
| 危機の基準 | 1.0未満＝自力で行政サービスを賄えない。低いほど国への依存度が高い |
| 住民への伝え方 | 「1.0なら自力で運営できるライン。うちのまちは○○」 |

**可視化**: 折れ線グラフ。1.0のラインを基準線として強調表示。下降トレンドを赤系の色で表現。

---

### A2. 積立金現在高 — 財政調整基金（まちの貯金）

| 項目 | 内容 |
|------|------|
| 決算カード取得元 | その他 → 積立金現在高（財政調整基金） |
| 値の意味 | 自治体の「いざという時の貯金」の残高 |
| 危機の基準 | 減少トレンド＝貯金を切り崩して生活。ゼロに近づくと非常事態 |
| 住民への伝え方 | 「まちの貯金はあと○億円。10年前は○億円ありました」 |

**可視化**: 棒グラフ（年度別）。残高が減るにつれ棒の色が緑→黄→赤に変化。

---

### A3. 地方債現在高（まちの借金残高）

| 項目 | 内容 |
|------|------|
| 決算カード取得元 | その他 → 地方債現在高 |
| 値の意味 | 自治体が抱えている借金の総額 |
| 危機の基準 | 増加トレンド＝借金が膨らんでいる |
| 住民への伝え方 | 「まちの借金は○億円。住民1人あたり○万円です」 |

**可視化**: 棒グラフ（年度別）。増加するにつれ色が濃くなる。1人あたり換算値を併記。

---

### A4. 経常収支比率（自由に使えるお金の余裕度）

| 項目 | 内容 |
|------|------|
| 決算カード取得元 | 財政指標 / 歳出・性質別の経常収支比率列 |
| 値の意味 | 経常的な収入のうち、経常的な経費に充てた割合 |
| 危機の基準 | 100%に近い＝収入のほぼ全てが固定費に消え、新しいことに使える余裕がない。一般的に75%以下が望ましいとされる |
| 住民への伝え方 | 「収入100円のうち○円は毎年決まった支出で消えます。自由に使えるのは○円だけ」 |

**可視化**: 折れ線グラフ。75%と100%にガイドラインを表示。100%に近づくにつれ背景色を赤に。

---

### A5. 人口推移

| 項目 | 内容 |
|------|------|
| 決算カード取得元 | メタデータ → 住民基本台帳人口 |
| 値の意味 | まちの住民数 |
| 危機の基準 | 減少トレンド＝税収減、1人あたり負担増の根本原因 |
| 住民への伝え方 | 「○年間で○人減りました。1人あたりの負担は○%増えています」 |

**可視化**: 面グラフ。年少人口・生産年齢人口・老年人口の構成比も併記できると理想だが、決算カードには年齢構成はないため総数のみ。将来推計人口（国立社会保障・人口問題研究所）を重ねられると訴求力が上がる（Phase 2以降の拡張候補）。

---

### A6. 自主財源比率（自分たちで稼いだお金の割合）

| 項目 | 内容 |
|------|------|
| 決算カード取得元 | 歳入 → 地方税の構成比、または一般財源計の構成比 |
| 値の意味 | 歳入全体に占める地方税等の自主財源の割合 |
| 危機の基準 | 低下トレンド＝国や道への依存が深まっている |
| 住民への伝え方 | 「収入のうち、自分たちで稼いだお金は○%だけ。残りは国や道からもらっています」 |

**可視化**: 積み上げ面グラフ。自主財源（地方税等）と依存財源（交付税・国庫支出金等）を色分け。

---

### A7. 扶助費の推移（福祉・医療にかかるお金）

| 項目 | 内容 |
|------|------|
| 決算カード取得元 | 歳出・性質別 → 扶助費 |
| 値の意味 | 生活保護、児童福祉、高齢者福祉等に充てた経費 |
| 危機の基準 | 増加トレンド＝高齢化で義務的支出が膨張し、他に回す余裕が減る |
| 住民への伝え方 | 「福祉・医療のお金は10年で○倍に。まちの支出の○%を占めています」 |

**可視化**: 棒グラフ（年度別）。歳出総額に対する構成比も併記。

---

### A8. 普通建設事業費の推移（未来への投資）

| 項目 | 内容 |
|------|------|
| 決算カード取得元 | 歳出・性質別 → 普通建設事業費 |
| 値の意味 | 道路・学校・公共施設など、インフラへの投資額 |
| 危機の基準 | 減少トレンド＝インフラ投資ができなくなっている。老朽化が進む |
| 住民への伝え方 | 「道路や建物の工事費は10年前の○分の1。古くなった施設を直すお金がありません」 |

**可視化**: 棒グラフ（年度別）。減少をグレーアウトで表現。

---

### A9. 実質公債費比率（借金返済のキツさ）

| 項目 | 内容 |
|------|------|
| 決算カード取得元 | 財政指標 |
| 値の意味 | 標準財政規模に対する実質的な借金返済額の割合（3年平均） |
| 危機の基準 | 18%以上＝新たな借金に許可が必要（起債許可団体）。25%以上＝一部の起債が制限 |
| 住民への伝え方 | 「稼ぎに対する借金返済の割合は○%。18%を超えると国の管理下に入ります」 |

**可視化**: 折れ線グラフ。18%と25%にアラートラインを表示。

---

## B. スナップショット型指標

### B1. 歳入の地方交付税依存率（国からの仕送り依存度）

| 項目 | 内容 |
|------|------|
| 決算カード取得元 | 歳入 → 地方交付税の構成比 |
| 危機の見せ方 | 「収入の○%が国からの仕送り」 |

**可視化**: ドーナツチャート。地方交付税の部分を赤系で強調。中央に依存率を大きく表示。

---

### B2. 義務的経費比率（削れない支出の割合）

| 項目 | 内容 |
|------|------|
| 決算カード取得元 | 歳出・性質別 → 義務的経費計（人件費＋扶助費＋公債費） |
| 危機の見せ方 | 「収入の○%は給料・福祉・借金返済で消えます」 |

**可視化**: 横棒バー1本。義務的経費部分を赤系で塗りつぶし、残りの部分（自由に使える額）を緑で表示。バーの大半が赤で埋まっている状態が一目で伝わる。

---

### B3. 住民1人あたり地方債残高（あなたが背負っている借金）

| 項目 | 内容 |
|------|------|
| 決算カード取得元 | 地方債現在高 ÷ 住民基本台帳人口 |
| 危機の見せ方 | 「あなたの分は○万円です」 |

**可視化**: 大きな数字で中央に表示。日常の出費と比較できるよう「住宅ローン○年分」等の換算を添える。

---

### B4. 住民1人あたり積立金残高（あなたの分の貯金）

| 項目 | 内容 |
|------|------|
| 決算カード取得元 | 積立金現在高（全基金合計）÷ 住民基本台帳人口 |
| 危機の見せ方 | 「あなたの分の貯金は○万円です」 |

**可視化**: B3と並べて表示。借金と貯金の差が視覚的に伝わる天秤やバランスバー。

---

### B5. 類似団体との乖離（似たまちとの比較）

| 項目 | 内容 |
|------|------|
| 決算カード取得元 | 全項目の「類似団体」列 |
| 危機の見せ方 | 「同じ規模のまちの平均は○なのに、うちは○」 |

**可視化**: 各指標に類似団体平均値をグレーのマーカーで併記。自団体の値が平均より悪い場合は赤で強調。

---

### B6. 民生費構成比（福祉にかかるお金の割合）

| 項目 | 内容 |
|------|------|
| 決算カード取得元 | 歳出・目的別 → 民生費の構成比 |
| 危機の見せ方 | 「歳出の○割が福祉関連です」 |

**可視化**: 歳出目的別のツリーマップまたはワッフルチャート。民生費の面積の大きさが直感的に伝わる。

---

### B7. 実質収支（今年の赤字/黒字）

| 項目 | 内容 |
|------|------|
| 決算カード取得元 | 財政指標 → 実質収支 |
| 危機の見せ方 | 赤字なら「今年は○億円の赤字です」 |

**可視化**: 黒字なら緑、赤字なら赤の大きな数字。シンプルに見せる。

---

## C. 組み合わせ型指標

### C1. 貯金↓ × 借金↑ ハサミグラフ

| 項目 | 内容 |
|------|------|
| 使用指標 | A2（積立金現在高）+ A3（地方債現在高） |
| 伝わるメッセージ | 「貯金が減って、借金が増えている」 |

**可視化**: 2本の折れ線を同一グラフに重ねる。積立金の線（緑→下降）と地方債の線（赤→上昇）が交差するポイントが視覚的にインパクト大。交差後の領域を薄い赤で塗りつぶし「借金が貯金を上回っている期間」を強調する。

**表示例イメージ**:

```
金額
 │  ＼借金（地方債）
 │    ＼          ／
 │      ＼      ／
 │        ×  ← この交差が「転換点」
 │      ／  ＼
 │    ／      ＼
 │  ／  貯金（積立金）＼
 └──────────────────────→ 年度
```

---

### C2. 人口↓ × 扶助費↑

| 項目 | 内容 |
|------|------|
| 使用指標 | A5（人口）+ A7（扶助費） |
| 伝わるメッセージ | 「人が減っているのに福祉のお金は増え続けている」 |

**可視化**: 2軸の折れ線グラフ。左軸に人口（下降）、右軸に扶助費（上昇）。2つの線が開いていく「ワニの口」型のグラフ。

---

### C3. 義務的経費↑ × 建設事業費↓

| 項目 | 内容 |
|------|------|
| 使用指標 | B2（義務的経費）+ A8（普通建設事業費） |
| 伝わるメッセージ | 「削れない支出が増えて、未来への投資ができなくなっている」 |

**可視化**: 積み上げ面グラフ。義務的経費（赤）が面積を広げ、建設事業費（青）が圧迫されて薄くなっていく様子。

---

### C4. 1人あたり借金 vs 1人あたり貯金 バランスバー

| 項目 | 内容 |
|------|------|
| 使用指標 | B3（1人あたり地方債残高）+ B4（1人あたり積立金残高） |
| 伝わるメッセージ | 「あなたの分の借金○万円、貯金○万円」 |

**可視化**: 天秤のイラスト、または左右に伸びるバー。借金側（赤）と貯金側（緑）の長さの差が一目で伝わる。

**表示例イメージ**:

```
貯金  5万円 ██                        ██████████████████████ 50万円  借金
           ←──── あなたが背負っている差額: 45万円 ────→
```

---

### C5. 経常収支比率 × 財政力指数 4象限マップ

| 項目 | 内容 |
|------|------|
| 使用指標 | A4（経常収支比率）+ A1（財政力指数） |
| 伝わるメッセージ | 「稼ぐ力」と「やりくりの余裕」の両方で今のまちの位置がわかる |

**可視化**: 散布図。X軸に財政力指数、Y軸に経常収支比率。4象限を色分け:

```
経常収支比率（高=余裕なし）
     │
  危険 │ 要注意
  稼げない＆  │ 稼げるが
  余裕なし   │ 余裕なし
─────┼─────→ 財政力指数（高=稼げる）
  要改善 │ 健全
  稼げないが  │ 稼げる＆
  余裕あり   │ 余裕あり
     │
```

自分のまちを大きなドットで、北海道内の他の自治体を小さなドットで表示。自分のまちがどの位置にいるかが一目でわかる。

## 実装の優先順位

「見た瞬間に刺さる」インパクトと実装の容易さを軸に優先度を付ける。

### 第1群（最小構成・これだけでも訴求力あり）

| 指標 | 理由 |
|------|------|
| **C4: 1人あたり借金 vs 貯金** | 最もシンプルで最も刺さる。計算は割り算のみ |
| **B2: 義務的経費バー** | バー1本の描画。「自由に使えるお金」の少なさが一目瞭然 |
| **C1: 貯金×借金ハサミグラフ** | 折れ線2本。経年変化の危機感を最も直感的に伝える |

### 第2群（第1群に追加して深みを出す）

| 指標 | 理由 |
|------|------|
| **A4: 経常収支比率の推移** | 第1群の「なぜ余裕がないか」の裏付け |
| **C2: 人口×扶助費** | 構造的な問題を伝える。少子高齢化の文脈とつながる |
| **B5: 類似団体比較** | 決算カードに値が入っているため追加コストが低い |

### 第3群（比較・分析の充実）

| 指標 | 理由 |
|------|------|
| **A1: 財政力指数** | 他の指標の背景説明として有用 |
| **C5: 4象限マップ** | 複数自治体の位置関係を俯瞰。データが揃ってから |
| **A9: 実質公債費比率** | 18%/25%のアラートラインがわかりやすい |
