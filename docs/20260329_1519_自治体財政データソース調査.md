# 自治体財政データソース調査

## 目的

**北海道内自治体の財政データを取り込む**にあたり、利用可能なデータソースの種類・形式・取得方法・粒度を整理し、本プロジェクトに最適なデータソースを選定する。

---

## データソース一覧

### 1. 決算カード（総務省統一様式）

全自治体が毎年度、総務省に提出する統一フォーマットの財政サマリー。1自治体の歳入・歳出・財政指標を1シートに集約したもの。

| 項目 | 内容 |
|------|------|
| 公開元 | 総務省 |
| URL | https://www.soumu.go.jp/iken/zaisei/card.html |
| 形式 | Excel（.xlsx）、PDF |
| 単位 | 都道府県別に1ファイル（北海道分は全市町村が1ファイルに収録） |
| 収録年度 | 平成13年度（2001）〜 令和5年度（2023） |
| 更新頻度 | 年1回（決算確定後、翌年度の秋〜冬頃） |

#### 収録項目

**メタデータ:**
- 団体名、市町村類型、地方交付税種地
- 人口（国勢調査ベース、2年分＋増減率）
- 住民基本台帳人口（2年分＋増減率）
- 産業構造（第1次・第2次・第3次）
- 面積、人口密度

**歳入（約28項目）:**
- 地方税、地方譲与税、各種交付金（利子割、配当割、地方消費税 等）
- 地方交付税（普通＋特別の内訳あり）
- 国庫支出金、都道府県支出金
- 分担金・負担金、使用料、手数料
- 財産収入、寄附金、繰入金、繰越金、諸収入
- 地方債
- 各項目に「決算額」「構成比」「経常一般財源等」の列あり
- **類似団体の平均値**も併記（比較用）

**歳出・目的別（約15項目）:**
- 議会費、総務費、民生費、衛生費、労働費
- 農林水産業費、商工費、土木費、消防費、教育費
- 災害復旧費、公債費
- 各項目に「決算額」「うち普通建設事業費」「充当一般財源等」の列あり

**歳出・性質別（約15項目）:**
- 人件費（うち職員給）、扶助費、公債費 → 義務的経費計
- 物件費、維持補修費、補助費等
- 積立金、投資・出資・貸付金、繰出金
- 普通建設事業費（補助/単独の内訳）、災害復旧事業費
- 各項目に「決算額」「構成比」「経常収支比率」の列あり

**財政指標:**
- 経常収支比率、財政力指数、実質収支比率
- 実質公債費比率、公債費負担比率
- 基準財政収入額、基準財政需要額、標準財政規模

**その他:**
- 職員数（部門別）、人口千人当たり職員数
- 特別職の給料（首長、副首長、議長、議員）
- 積立金現在高（財政調整基金、減債基金、その他）
- 地方債現在高

#### 本プロジェクトでの評価

| 観点 | 評価 |
|------|------|
| 取り込みやすさ | **高** — Excel統一フォーマット、都道府県別1ファイル |
| 粒度 | 款レベル（大分類）— サンキー図の表現に十分 |
| カバー範囲 | 北海道全179市町村＋道 |
| 経年比較 | 容易（20年以上のデータあり） |
| 人口データ | 含まれている（国勢調査＋住民基本台帳） |
| 類似団体比較 | 含まれている |

### 2. e-Stat 地方財政状況調査（機械可読データ）

決算カードと同じ元データを、政府統計ポータル「e-Stat」経由でCSV/JSON等の機械可読形式でダウンロードできる。

| 項目 | 内容 |
|------|------|
| 公開元 | 総務省（e-Stat経由） |
| URL | https://www.e-stat.go.jp/stat-search/files?toukei=00200251&tstat=000001077755 |
| 形式 | CSV（Shift-JIS / UTF-8 / UTF-8 BOM）、Excel、XML、JSON |
| データ件数 | 市町村データ 4,973件、都道府県データ 2,424件 |
| 収録年度 | 平成元年度（1989）〜 令和7年度（2025）※最新更新2025年12月 |

#### 収録内容

- 歳入内訳（決算カードと同等の項目）
- 歳出内訳及び財源内訳（目的別・性質別）
- データベース検索インタフェースあり（自治体名・年度で絞り込み可能）

#### 本プロジェクトでの評価

| 観点 | 評価 |
|------|------|
| 取り込みやすさ | **最も高い** — CSV/JSON形式、プログラムで直接パース可能 |
| 粒度 | 決算カードと同等（款レベル） |
| カバー範囲 | 全国全自治体 |
| 経年比較 | 30年以上のデータ |
| API | なし（ファイルダウンロードのみ） |

### 3. 市町村別決算状況調

決算カードをさらに詳細化した調査データ。普通会計・特別会計に分かれる。

| 項目 | 内容 |
|------|------|
| 公開元 | 総務省 |
| URL | https://www.soumu.go.jp/iken/kessan_jokyo_2.html |
| 形式 | Excel（.xlsx）— 年度あたり10ファイル（普通会計5＋特別会計5） |
| 収録年度 | 平成14年度（2002）〜 令和6年度（2024） |

#### 収録内容

- 普通会計: サマリー、起債情報、目的別歳出、一般財源充当歳出、起債管理
- 特別会計: 同上の構造
- 決算カードより詳細な内訳（款・項レベル）

#### 本プロジェクトでの評価

| 観点 | 評価 |
|------|------|
| 取り込みやすさ | 中 — Excelだがファイル数が多く構造が複雑 |
| 粒度 | 款・項レベル（中分類）— ドリルダウン表示に有用 |
| カバー範囲 | 全国全市町村 |
| 用途 | 決算カードで不足する詳細が必要になった場合の拡張データ |

### 4. 主要財政指標一覧

全自治体の主要財政指標を一覧にまとめたもの。自治体間比較に最適。

| 項目 | 内容 |
|------|------|
| 公開元 | 総務省 |
| URL | https://www.soumu.go.jp/iken/shihyo_ichiran.html |
| 形式 | Excel（.xlsx）、PDF — 年度あたり8ファイル |
| 収録年度 | 平成15年度（2003）〜 令和6年度（2024） |

#### 収録指標

- 財政力指数
- 経常収支比率
- 実質公債費比率
- 将来負担比率
- ラスパイレス指数

#### 本プロジェクトでの評価

| 観点 | 評価 |
|------|------|
| 取り込みやすさ | 高 — Excelで全自治体が一覧 |
| 用途 | 自治体間比較、「通信簿」的な表示、健全度ランキング |
| 決算カードとの重複 | 一部重複（決算カードにも財政指標あり）。ただし一覧性はこちらが上 |

### 5. 財政状況資料集

決算カード＋財政比較分析＋健全化判断比率を1パッケージにした資料。自治体ごとに1ファイル。

| 項目 | 内容 |
|------|------|
| 公開元 | 総務省（都道府県経由で個別自治体分も公開） |
| URL（総務省） | https://www.soumu.go.jp/iken/zaisei/jyoukyou_shiryou/index.html |
| URL（北海道庁） | https://www.pref.hokkaido.lg.jp/ss/scs/zaisei/shi-zaisei-4-1-0.html |
| 形式 | Excel（.xlsx）、PDF |
| 収録年度 | 平成22年度（2010）〜 令和5年度（2023） |

#### 北海道庁ページの構成

- 北海道内14振興局（空知、石狩、後志、胆振、日高、渡島、檜山、上川、留萌、宗谷、オホーツク、十勝、釧路、根室）ごとにZIPファイル
- 各ZIPに振興局管内全市町村の資料が収録
- 令和6年度（2024）の財政状況資料集が最新

#### 収録内容

- 決算カード相当のデータ
- 類似団体との比較分析（レーダーチャート用データ含む）
- 健全化判断比率（実質赤字比率、連結実質赤字比率、実質公債費比率、将来負担比率）
- 経年推移データ

#### 本プロジェクトでの評価

| 観点 | 評価 |
|------|------|
| 取り込みやすさ | 中 — 自治体ごとに個別ファイルのため、一括取得にはスクレイピング的な手順が必要 |
| 粒度 | 決算カード＋α（比較分析データを含む） |
| 用途 | 類似団体比較、健全度評価に有用 |

### 6. 健全化判断比率（法定4指標）

地方公共団体の財政の健全化に関する法律に基づく、法定の財政健全度指標。

| 項目 | 内容 |
|------|------|
| 公開元 | 総務省 |
| URL | https://www.soumu.go.jp/iken/zaisei/kenzenka/index10.html |
| 形式 | Excel（.xlsx）、ZIP |

#### 法定4指標

1. **実質赤字比率** — 一般会計等の赤字の程度
2. **連結実質赤字比率** — 全会計を連結した赤字の程度
3. **実質公債費比率** — 借金返済の負担の程度
4. **将来負担比率** — 将来支払うべき負債の程度

＋ 資金不足比率（公営企業ごと）

#### 本プロジェクトでの評価

| 観点 | 評価 |
|------|------|
| 用途 | 「うちのまちは大丈夫？」という住民の不安に直接応える指標 |
| 取得方法 | 主要財政指標一覧（データソース4）または財政状況資料集（データソース5）から取得可能 |

## 推奨：段階的なデータ取り込み戦略

### Phase 1（MVP）— 決算カードまたはe-Stat

- **データソース**: 決算カード（Excel）または e-Stat（CSV）
- **対象**: 北海道内全市町村＋道
- **取得項目**: 歳入（款別）、歳出・目的別（款別）、歳出・性質別（款別）、人口、主要財政指標
- **年度**: 直近2〜3年度分
- **実現できるUI**:
  - サンキー図（歳入→歳出の流れ）
  - 財務サマリー（収入総額・支出総額・収支）
  - ひとことサマリー（テンプレートベース）
  - 住民1人あたり換算（人口データが含まれている）
  - 経年変化ハイライト（複数年度分取り込み）

決算カードとe-Statは同じ元データだが、e-StatのCSV/JSONのほうがパーサー実装が容易。ただし、決算カードのExcelには類似団体平均値が含まれており、比較表示に活用できる利点がある。

### Phase 2（比較・健全度）— 主要財政指標一覧

- **データソース**: 主要財政指標一覧（Excel）
- **追加取得項目**: 財政力指数、経常収支比率、実質公債費比率、将来負担比率
- **実現できるUI**:
  - 自治体間比較（同規模自治体との並列表示）
  - 財政健全度スコアカード
  - 北海道内ランキング

### Phase 3（詳細化）— 市町村別決算状況調

- **データソース**: 市町村別決算状況調（Excel）
- **追加取得項目**: 款・項レベルの詳細内訳
- **実現できるUI**:
  - ドリルダウン（「教育費」→「小学校費」「中学校費」等）
  - 特別会計（国民健康保険、介護保険等）の可視化

## 現行システムとの関係

現在のadmin data-importコンテキストはマネーフォワードCSVの取り込みに特化している（`MfCsvLoader`, `MfRecordConverter`等）。自治体財政データの取り込みでは以下の変更が必要になる。

- **パーサーの差し替え**: MfCsvLoader → 決算カードExcelパーサー or e-Stat CSVパーサー
- **歳入歳出科目体系の差し替え**: `shared/accounting/account-category.ts`の政治資金カテゴリ → 自治体財政の款・項体系
- **データモデルの拡張**: 既存のTransactionモデル（個別取引ベース）に加え、年度×カテゴリの集計データを直接保持するモデルの検討
  - 決算カードのデータは個別取引ではなく、年度ごとの集計値であるため

ただし、既存のサンキー図・月次チャート・財務サマリー等のUIコンポーネントは、データの入口（loader/usecase）さえ差し替えれば再利用可能。
